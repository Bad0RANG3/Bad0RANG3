## About

我是 Bad0RANG3，喜欢把感兴趣的东西拆开看看，也喜欢把突然冒出来的想法做成能跑的小项目。

- 对逆向、网络包、客户端行为和奇怪的边界情况比较感兴趣。
- 偶尔做音乐、剪视频、调视觉效果，也会打 MaimaiDX、CS2。
